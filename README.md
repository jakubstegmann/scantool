# Premenovanie faktúr 2.0

Webová aplikácia, ktorá prečíta naskenované PDF faktúry (OCR priamo v prehliadači), nájde číslo faktúry
a dodávateľa a súbory skopíruje pod novým názvom. Faktúry sa nikam nenahrávajú.

Prihlásenie cez Google, schvaľovanie používateľov správcom (`admin.html`) a spoločné naučené opravy (Firebase).
Vyžaduje Google Chrome alebo Microsoft Edge na počítači (výber priečinkov).

Predchádzajúca verzia 1.0 (bez prihlasovania) je zálohovaná vo vetve `v1-backup` a v značke `v1.0`.
